# Bibliography

1. **Hu et al., 2022, ICLR** – *LoRA: Low-Rank Adaptation of Large Language Models*. Proposes **LoRA**, which freezes a pre-trained transformer and injects trainable low-rank matrices *A,B* into each layer. This reduces trainable parameters by ~10,000× (and GPU memory by 3×) while matching or exceeding full fine-tuning performance. *Key technique:* Represent weight updates as a low-rank decomposition (rank-*$d_{\rm int}$) so only *A* and *B* (with *A: R^{d\times d_{int}}, B: R^{d_{int}\times d}*) are trained. *Quantitative result:* Demonstrated on GPT-3 175B, LoRA-trained models reached comparable quality to full fine-tune with dramatically fewer parameters (10K× reduction). *Relevance:* Foundational PEFT method; provides the “LoRA” module concept that we will adapt to CNN (e.g., into 1×1 conv layers). THESIS-QUOTE: “We propose Low-Rank Adaptation (LoRA), which **freezes** the pre-trained model weights and injects trainable rank-decomposition matrices into each layer… greatly reducing the number of trainable parameters for downstream tasks”.

2. **Dettmers et al., 2024 (NeurIPS)** – *QLoRA: Efficient Finetuning of Quantized LLMs*. Introduces **QLoRA**, which fine-tunes large LLMs by **freezing a 4-bit quantized base model** and backpropagating into LoRA adapters. They introduce the NF4 (normalfloat4) 4-bit format and other tricks to enable 4-bit training on a single GPU. *Key technique:* Quantize a pre-trained model to 4-bit (with per-tensor zero-points) and train LoRA *A,B* on top of the frozen quantized weights. The pre-quantization (“double quantization”) and LoRA enable memory-saving. *Quantitative result:* They fine-tune 65B-parameter models on a single 48GB GPU (Guanaco models) and achieve state-of-art instruction-following (99.3% of ChatGPT’s Vicuna score). *Relevance:* Shows that LoRA plus quantization can retain full 16-bit accuracy even at 4-bit weights. We can draw on its ideas for applying quantized LoRA to other architectures. THESIS-QUOTE: “QLoRA backpropagates gradients through a frozen, **4-bit quantized** pretrained language model into Low-Rank Adapters (LoRA)… Our Guanaco models achieve 99.3% of ChatGPT’s performance while requiring only 24h of finetuning on one GPU”.

3. **Xu et al., 2024, ICLR** – *QA-LoRA: Quantization-Aware Low-Rank Adaptation*. Proposes **QA-LoRA**, which integrates quantization into the LoRA finetuning pipeline. They use *group-wise quantization* to increase quantization degrees of freedom and allow merging LoRA adapters into the quantized weights. *Key technique:* During fine-tuning, weights are quantized to low-bit (e.g. INT4), and LoRA updates are learned so that **post-merge**, the sum *(quantized W + s·A·B)* still fits in low-bit. They derive the merge rule (new zero-point β′ = β + s·A·B) to incorporate LoRA into quantized weights without high-precision intermediates. *Quantitative result:* QA-LoRA achieves the accuracy of full-precision LoRA fine-tuning **without post-training quantization (PTQ)**. (E.g. on LLaMA-7B MMLU, QA-LoRA at INT4 matches or exceeds QLoRA.) *Relevance:* QA-LoRA provides the exact formulas for scaling and merging that we need to apply LoRA in a quantized CNN context. THESIS-QUOTE: “We propose QA-LoRA, which uses group-wise operators to **quantize weights during fine-tuning** and allows the quantized base weights and LoRA updates to be merged without accuracy loss. Our method requires no PTQ and can integrate the adapted weights into an INT4 model”.

4. **Zhong et al., 2024, ICLR** – *Convolution Meets LoRA: PEFT for Segment Anything Model*. Introduces **Conv-LoRA**, adapting LoRA to vision by injecting small convolutional kernels into a pre-trained ViT (SAM). This explicitly embeds CNN-like local bias. *Key technique:* Add ultra-lightweight convolutional layers (Conv-LoRA blocks) into each transformer block of SAM; these behave like 1×1 or depthwise conv adapters. This preserves the global ViT weights while fine-tuning only the new conv parameters. *Quantitative result:* On diverse segmentation benchmarks, Conv-LoRA significantly outperforms plain LoRA (ViT) for adapting SAM to specialized domains. *Relevance:* Demonstrates that *LoRA-like low-rank updates* can be implemented as convolutional filters in vision models. We can similarly apply LoRA or QLoRA by treating 1×1 convs as low-rank linear layers. THESIS-QUOTE: “Conv-LoRA injects ultra-lightweight convolutional parameters into the LoRA framework to inject image-related inductive biases… experiments show Conv-LoRA’s superiority in adapting SAM to real-world segmentation tasks.”

# Synthesis

- **LoRA (Hu et al.)** – A fundamental PEFT method for Transformers. It freezes the pre-trained weights and adds *trainable low-rank adapters* to each layer, drastically cutting the number of tunable parameters. Though originally for NLP, the core idea applies to any linear layer. For CNNs, each convolution (especially 1×1 conv) can be seen as a linear map; we can inject LoRA by adding two smaller 4D tensors (A,B) whose product has the same shape as the conv kernel. Zhong et al. (2024) effectively do this by inserting small convolution filters in a ViT. Thus, to apply LoRA to EfficientNet’s 1×1 conv layers, one would create adapter-tensors (of shape [out,ch,int] and [int,ch_out,1]) and freeze the original weights. The LoRA approach retains inference speed (no extra latency) and requires no FP16 activations.

- **QLoRA (Dettmers et al.)** – Enhances LoRA for **quantized models**. QLoRA first quantizes the base model’s weights to 4 bits (using a normalfloat-4 format) and then learns LoRA adapters on top while backpropagating through the frozen quantized weights. The key insight is that 4-bit weights suffice to preserve full fine-tuning accuracy with LoRA. For EfficientNet, one could analogously quantize convolutional weights to 4 bits during training. Dettmers et al. show that 4-bit quantization (with appropriate scaling and bias per tensor) yields negligible accuracy loss when combined with LoRA. In practice, this uses a mapping W_int4 = clamp(round(W/α + z),−8,7) where α = (max−min)/15 and z encodes the zero-point. After training, the LoRA updates remain in this 4-bit space (thanks to QA-LoRA’s merge rule below).

- **QA-LoRA (Xu et al.)** – Introduces *quantization-aware* training to LoRA. The crucial property is that **after fine-tuning, the frozen quantized weights and the low-rank adapters can be merged into a new quantized weight tensor** without floating-point operations. They show mathematically that by choosing the quantization groupings and zero-point properly, one can compute a new scale/zero (β′) that absorbs the LoRA update s·A·B. Specifically, if original W is quantized with scale α and zero β, then after LoRA update we have W_new = α·(W_int4 − β) + s·A·B. One can merge by adjusting the zero-point: β′ = β + s·A·B (using per-group addition) so that W_new remains representable in INT4. In practice, this means for EfficientNet we would quantize each 1×1 conv’s weights (possibly per-channel) and learn LoRA adapters; after training, we update the bias (zero-point) such that no additional FP math is needed. QA-LoRA validates this on LLMs but the algebra extends to any linear map.

- **Conv-LoRA and CNN adaptation** – Zhong et al. show that adding *convolutional* adapters to a ViT can capture local structure. For EfficientNet, which is already convolutional, one approach is to treat each 1×1 conv as a linear layer and apply LoRA (i.e., add two smaller 1×1 convolutions that multiply to a rank-*$d_{int}$ update). Alternatively, one could use small depthwise or pointwise convolutions as adapters (as Conv-LoRA does). Either way, the LoRA idea generalizes to CNNs: we inject trainable parameters into convolutional layers and keep the original weights frozen. Combined with QLoRA/QA-LoRA, this yields a hybrid scheme: freeze and quantize the EfficientNet weights to INT4, then learn small low-rank conv filters and finally merge them into the quantized model.
